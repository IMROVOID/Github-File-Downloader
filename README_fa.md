# دانلودر فایل گیتهاب

یک گردش کار قدرتمند GitHub Actions که هر فایلی را از وب مستقیماً در مخزن شما دانلود می‌کند. این ابزار به‌طور خودکار فایل‌ها را سازمان‌دهی، فشرده‌سازی و برای فایل‌های حجیم تقسیم می‌کند، فایل‌های README دقیق تولید می‌کند و از آرشیوهای محافظت‌شده با رمز عبور پشتیبانی می‌نماید – همه بدون نیاز به هیچ‌گونه تنظیمات محلی.

> **پروژه پایه:** این گردش کار به‌شدت از ایده‌های [UDL-3](https://github.com/nikzad-avasam/UDL-3/) الهام گرفته و بر پایه آن ساخته شده است. از نویسندگان اصلی بابت کار پیشگامانه‌شان بسیار سپاسگزاریم!

## ✨ ویژگی‌های کلیدی

### قابلیت‌های عمومی و اصلی
- **🌐 دانلود جهانی:** دانلود هر فایلی از هر URL مستقیم. پشتیبانی از دانلود تکی و گروهی (چندین URL جدا شده با فاصله).
- **🔄 موتور دانلود مقاوم:** ترکیب `aria2` (برای انتقالات سریع و چند-اتصاله) و `curl` (به‌عنوان جایگزین) با منطق تلاش مجدد هوشمند برای مدیریت اتصالات ناپایدار.
- **📦 ذخیره‌سازی آرشیو یا ساده:** انتخاب بین حالت `normal` (ذخیره فایل‌ها به همان صورت) یا حالت `zip` (فشرده‌سازی در یک آرشیو ۷z).
- **🔐 رمزنگاری اختیاری:** محافظت از آرشیوها با یک رمز عبور. رمز عبور در فایل README تولید شده درج می‌شود تا هرگز فراموش نشود.
- **📏 تقسیم‌بندی قابل تنظیم:** تقسیم آرشیوهای بزرگ به بخش‌های کوچکتر (۱۰ تا ۹۰ مگابایت) برای دور زدن محدودیت‌های آپلود یا آسان‌تر کردن اشتراک‌گذاری.
- **⚙️ فشرده‌سازی تطبیقی:** انتخاب یک پیش‌فرض (`auto`، `best`، `great`، `good`، `fast`، `fastest`)؛ حالت `auto` هوشمندانه بالاترین سطح فشرده‌سازی را انتخاب می‌کند که بتواند در محدودیت زمانی گردش کار به پایان برسد.
- **📂 Push تدریجی گیت:** فایل‌ها در دسته‌های کوچک commit و push می‌شوند تا از خطاهای timeout حتی در مخازن چند ده گیگابایتی جلوگیری شود.

### ویژگی‌های خاص و منحصربه‌فرد
- **🕒 سازمان‌دهی بر اساس زمان:** هر بار اجرا یک پوشه با نام یکتا مانند `download_20260514_140437` یا `archive_20260514_140437` ایجاد می‌کند. دیگر خبری از بازنویسی فایل‌ها نیست.
- **📋 READMEهای خودکار:** هر پوشه/آرشیو دانلود به‌طور خودکار یک `README.md` جامع دریافت می‌کند که شامل موارد زیر است:
  - لیست تمام فایل‌ها به همراه اندازه آنها
  - زمان شروع اجرای کار
  - سطح فشرده‌سازی و تعداد بخش‌ها (در صورت آرشیو بودن)
  - محتویات آرشیو ۷z (تا دقیقاً بدانید چه چیزی داخل آن است بدون نیاز به دانلود)
- **🏗️ نمایش درختی stair-format:** فایل `downloads/README.md` اصلی نمای درختی از محتوای هر پوشه (۵ مورد اول) به همراه اندازه، تعداد بخش و زمان ایجاد را نشان می‌دهد – ایده‌آل برای مرور سریع.
- **📎 کپی تمام لینک‌ها با یک کلیک:** هر README شامل یک بلوک "مدیر دانلود" است که تمام لینک‌های بخش‌ها را فهرست کرده و آماده کپی و چسباندن در ابزارهایی مانند JDownloader می‌باشد.
- **🏋️ مدیریت فایل‌های حجیم:** با فایل‌های تا ۲۸ گیگابایت آزمایش شده و قادر به مدیریت دانلودهای بالای ۵۰ گیگابایت به لطف دسته‌بندی هوشمند و انتقال مبتنی بر resume.
- **🧠 نام‌گذاری هوشمند آرشیو:** در حالت `zip`، اگر فقط یک فایل دانلود شود، نام آرشیو از نام فایل اصلی گرفته می‌شود (در صورت طولانی بودن کوتاه می‌شود) به‌جای یک نام عمومی – تا خوانایی حفظ شود.

## 📁 ساختار پروژه

```
.
├── .github
│   └── workflows
│       └── download.yml          # فایل اصلی گردش کار
├── downloads                     # (بعد از اولین اجرا ایجاد می‌شود) تمام محتوای دانلود شده
├── README.md                     # این فایل
└── LICENSE                       # مجوز GNU GPL v3.0
```

تمام منطق در یک فایل گردش کار جای گرفته است. بدون نیاز به مراحل ساخت یا وابستگی خارجی – کافیست Fork کرده، پیکربندی کنید و اجرا نمایید.

## ⚙️ روش استفاده

1. **مخزن را Fork کنید** به حساب کاربری گیت‌هاب خود.
2. به تب **Actions** در Fork خود بروید.
3. گردش کار **⬇️ 01- Download URL** را از نوار کناری سمت چپ انتخاب کنید.
4. روی **"Run workflow"** کلیک کنید و ورودی‌ها را پر نمایید:
   - **URLs:** لینک(های) دانلود که با فاصله جدا شده‌اند.
   - **Mode:** حالت `normal` (ذخیره فایل‌ها به همان صورت) یا `zip` (فشرده‌سازی به یک آرشیو ۷z).
   - **Part size:** اندازه هر بخش از آرشیو تقسیم‌شده به مگابایت (۱۰-۹۰، پیش‌فرض ۴۵).
   - **Password:** (اختیاری) رمز عبور برای رمزنگاری آرشیو.
   - **Compression Preset:** سطح فشرده‌سازی را انتخاب کنید (پیشنهاد `auto`).
5. روی **"Run workflow"** کلیک کنید و منتظر بمانید تا عملیات تکمیل شود.
6. پس از اتمام، فایل‌های شما در پوشه `downloads/` با سازمان‌دهی بر اساس زمان و همراه با یک `README.md` دقیق ظاهر می‌شوند.

## 🔧 نحوه تغییر و شخصی‌سازی

تمام رفتار ابزار توسط فایل YAML موجود در مسیر `.github/workflows/download.yml` کنترل می‌شود. می‌توانید آن را مستقیماً در Fork خود ویرایش کنید تا موارد زیر را تغییر دهید:

- اندازه تقسیم پیش‌فرض یا سطح فشرده‌سازی
- حداکثر زمان دانلود (`timeout-minutes`)
- پارامترهای دسته‌بندی push گیت
- قراردادهای نام‌گذاری پوشه‌ها و آرشیوها
- محتوای فایل‌های README تولید شده به‌صورت خودکار

کافیست فایل را در ویرایشگر گیت‌هاب باز کنید، تغییرات خود را اعمال کنید و commit نمایید. اجرای بعدی از تنظیمات سفارشی شما استفاده خواهد کرد.
